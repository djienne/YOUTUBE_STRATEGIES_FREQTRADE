# COPY_HL research source

This source was previously misnamed `Market_Making.py` inside the Market_Making
package, but defines the separate `COPY_HL` strategy. It is preserved here with
the accompanying configuration as an experimental snapshot, not a validated
deployment. The actual Market_Making package is in `Strategies/Market_Making`.

Set `HYPERLIQUID_WALLET_ADDRESS` locally to choose the wallet to observe. No
personal wallet address is bundled. Review the configuration, Hyperliquid
dependencies and trading behavior before running it.
