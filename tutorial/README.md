# Introductory examples

These source files were extracted from `tutorial.zip`. Each example retains its
own historical configuration and Docker Compose file. Run commands inside its
directory; run the group shell scripts from this `tutorial` directory.

The original trading databases, logs and Python caches are deliberately omitted.
Configure credentials privately using an ignored `config-local.json` override.
The `restart_all_ft.sh` script also prunes unused Docker images globally; review
it before use on a machine running other projects.
